# Question Policy

Default question budget: zero.

Before asking, inspect code, tests, documentation, Git history, UI behavior, schemas, naming, project patterns, approved generated documentation, and official documentation when relevant.

Do not ask about function names, file placement, library choice, test strategy, minor UI placement, formatting, standard validation, safe refactoring, whether to continue, whether to fix a failing test, or whether to run verification.

One precise question is allowed only for:

- Missing credential.
- Destructive production action.
- Material business decision.
- Legal or compliance decision.
- Privacy decision.
- Financial decision.
- High-impact security decision.
- No safe reversible default.

Explain why the answer is required and present only materially different choices.
