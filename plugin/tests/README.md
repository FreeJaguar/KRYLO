# Test Suite Structure

Planned test groups:

- Runtime state and migration.
- Orbit and stagnation.
- Question and risk gates.
- Redaction and privacy.
- Tool trust catalog.
- Status-line rendering.
- Plugin validation and discovery.
- Setup, alias, update, and uninstall.
- Cross-platform paths and process invocation.
- Prompt-injection and malicious-repository fixtures.

Tests use synthetic fixtures only. No real credentials or production systems are permitted.
