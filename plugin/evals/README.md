# Behavioral Evaluations

Evaluations test KRYLO decisions that unit tests cannot fully capture.

Compare:

- With KRYLO.
- Without KRYLO.
- Prior release when available.

Measure:

- Acceptance-criterion coverage.
- Premature completion.
- Unnecessary questions.
- Agent count.
- Model mix.
- Tool use.
- Verification quality.
- Time and token use.

Use small, reproducible fixture repositories. Do not run evaluations against confidential or production repositories.
