# Definition of Done

A KRYLO task is complete only when all applicable conditions are proven:

- The requested behavior is implemented.
- Acceptance criteria are satisfied.
- Existing project conventions are followed.
- Relevant tests exist and pass.
- Type checking passes.
- Linting and formatting pass.
- Production build passes when applicable.
- Migration validation passes when applicable.
- Runtime behavior is checked where practical.
- Browser, responsive, RTL, and accessibility checks are complete where applicable.
- AI evaluations are complete where applicable.
- Performance claims have before-and-after evidence.
- Independent review is complete.
- Security and migration reviews are complete when applicable.
- Valid findings are resolved.
- Affected verification is repeated after corrections.
- Final diff and git status are inspected.
- No secret or unrelated change remains.
- No unresolved critical or high-severity finding remains.
- Remaining risks are documented.
- One explicit terminal state is reported.

Code written without evidence is not completion.
