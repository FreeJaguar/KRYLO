# Architecture Decision Records

ADRs record durable KRYLO decisions.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

## Rules

- Do not edit an accepted decision to hide history.
- Add a new ADR when a decision changes.
- Link superseding and superseded ADRs.
- Keep context factual and decision language explicit.
- Include operational and security consequences.

Use `docs/templates/adr-template.md` for new records.
