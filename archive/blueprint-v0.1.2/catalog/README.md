# Tool Trust Catalog

The catalog records reviewed and blocked tool identities.

## Required data

- Tool ID.
- Publisher.
- Source.
- Version or commit.
- Trust tier.
- Blocked ranges.
- Capabilities.
- Network and secret behavior.
- Environment restrictions.
- Review date and reviewer.
- Re-review triggers.

Catalog entries are security decisions and require review. A newer version than the reviewed version is not automatically trusted.
