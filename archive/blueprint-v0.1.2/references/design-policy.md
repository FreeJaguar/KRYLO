# Design Policy

For significant UI work, define target user, screen purpose, primary action, hierarchy, existing tokens and components, typography, spacing, responsive behavior, RTL, keyboard and focus behavior, reduced motion, loading, empty, error, disabled states, accessibility expectations, and visual non-goals.

Use available design and browser tools only when relevant. Avoid generic AI visual defaults and decorative complexity without product meaning.

A successful render is not sufficient. Inspect screenshots and interaction behavior at representative widths.
