# Completion Contract

KRYLO may report VERIFIED_COMPLETE only when all applicable conditions are supported by evidence:

- Requested behavior implemented.
- Acceptance criteria proven.
- Relevant tests pass.
- Type checking, lint, format, and build pass when applicable.
- Runtime, browser, migration, AI, performance, and security checks complete when applicable.
- Independent review complete.
- Valid findings resolved and affected checks repeated.
- Final diff and git status inspected.
- No secret or unrelated change remains.
- No unresolved critical or high-severity finding remains.
- Remaining risks documented.

A Builder summary, one passing test, or file edits are not sufficient evidence.
